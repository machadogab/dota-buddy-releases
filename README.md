# Dota Voice Helper — downloads

Alertas de voz no Dota 2 (no PC e no Discord), análise das partidas, plano de jogo pelos picks, guias de heróis, reviews e party do Discord. Windows.

**Baixe o `DotaVoiceHelper.exe` na página de [Releases](../../releases/latest).** É um arquivo só: as configurações ficam em `%APPDATA%\Dota Voice Helper`.

Depois de instalado, o próprio app avisa quando sai uma versão nova e se atualiza com um clique.

Este repositório tem só os executáveis publicados; o código-fonte é privado.
